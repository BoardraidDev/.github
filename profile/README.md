# BoardRaid
Minecraft Java 1.16.1 · Fabric · 任务竞赛

收集、探索与策略，围绕同一张任务卡板展开竞赛；也可在私人房间练习寻找末地传送门与宝藏竞赛。

| 入口 | 内容 |
| --- | --- |
| [官网](https://boardraid.cn/) | 下载、规则、排行榜与任务目录 |
| [Wiki](https://github.com/BoardraidDev/wiki) | 入门、玩法、回放、故障排查与文档贡献 |
| [API Docs](https://github.com/BoardraidDev/api-docs) | 已核对的公开只读 API 与契约 |
| [Releases](https://github.com/BoardraidDev/releases) | 正式版说明和官网下载索引 |

## 参与
先阅读对应仓库的 CONTRIBUTING.md，再提出 Issue 或 Pull Request。请写明版本和复现步骤，不公开令牌、玩家信息或安全漏洞。
文档仓库公开，游戏源码与运维仓库保持私有。公开贡献不授予生产部署权限。

## 发布原则
master 承载正式版本，release 用于体验服验证。体验服人工验证后再晋升正式版；用户文档的合并不自动发布游戏或部署服务器。

BoardRaid 是独立社区项目，非 Mojang / Microsoft 官方产品，与 MCSR Ranked、Draftout 无隶属关系。
